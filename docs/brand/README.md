# Vespertine brand

The logo, colours and type for anything public about Vespertine. See [brand-guide.pdf](brand-guide.pdf) (or the PNG) for the rules.

| File | Use |
|---|---|
| `logo.svg` / `logo.png` | Primary lockup (brass crescent + "vespertine"), for dark backgrounds |
| `logo-on-light.svg` / `.png` | The same, for light backgrounds |
| `logo-stacked*.svg` / `.png` | Crescent above the wordmark, for square spaces |
| `logo*-mono-ivory.svg`, `logo*-mono-black.svg` | One colour, for single-ink or embossed uses |
| `logo-on-obsidian.png`, `logo-stacked-on-obsidian.png` | Previews on the brand background |
| `mark.svg` / `mark.png`, `mark-flat.svg` | The crescent alone (gradient or flat brass) |

- **Wordmark:** always lowercase, set in Newsreader Light and outlined in the SVGs, so no font is needed to use them.
- **Colours:** the app's and the site's tokens.
  - Obsidian `#09090A`, surface `#16161A`, ivory `#ECE6DA`.
  - Brass `#C8A66A` (light `#E7CD98`, dark `#7C6541`).
  - Copper `#C98B5B` for "converted".
- **Type:** Newsreader, Inter and JetBrains Mono, all under the SIL Open Font License.
- **Don't use Apple's New York or SF fonts in artwork.** Their licence covers app interfaces only.

Everything here is generated by `scripts/brand/build.sh`. Edit the scripts, not the files.
