AirPods Max accept only 24-bit / 48 kHz over USB-C, so 44.1 kHz material has to be converted. Tracks already at 48 kHz play bit-perfect.
Palette
Obsidian surfaces are layered from #09090A up to #1C1C21 and separated by 7% warm hairlines. Text is warm ivory, never pure white. Brass is used only for active state, playback and bit-perfect status.
Type
New York for anything with a name: albums, tracks, artists in the hero. SF Pro for interface text. SF Mono for every number that describes the signal (sample rate, bit depth, gain) so the digits line up and read like instrument markings.
Truthful status
The BIT-PERFECT badge appears only when source rate = device rate, volume is at unity or on the hardware, there is no DSP, and the device is held exclusively. Every other state says in copper exactly what was changed.
