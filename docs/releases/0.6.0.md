**Nocturne is now Vespertine.**

The same player under a new name. Another open-source music player was already called Nocturne, so this one became Vespertine ("of the evening") before its public launch. The code, the sound and your library are unchanged.

### Coming from Nocturne
- **Nocturne doesn't update itself to Vespertine.** macOS apps can only replace themselves with an app that has the same identity, and Vespertine has a new one (`org.szeremeta.Vespertine`). Nocturne 0.5.19 tells you a new version exists and links here; download Vespertine and drag it into Applications.
- **On first launch Vespertine brings everything over by itself:**
  - your library, playlists, ratings, play counts, analysis, artwork and settings;
  - these are copied from Nocturne's folder as space-free APFS clones, and Nocturne's own files are left exactly as they were;
  - music you imported keeps going into ~/Music/Nocturne.
- **Once Vespertine opens with your library, you can delete Nocturne.**
- **If Nocturne is still open,** Vespertine asks you to quit it first, so the library isn't copied mid-write.
- **macOS asks again for a few permissions** because it treats Vespertine as a new app: network volumes, and the keychain item for a saved share password (choose *Always Allow*).
- **A ListenBrainz token has to be entered again** in Settings.
- **Servers running the share analyzer keep working as they are.** Vespertine reads results from `.nocturne/` as well as `.vespertine/`.

### New
- **Rename sources in the sidebar** (right-click → *Rename…*). Only the sidebar name changes, not the folder. The folder Vespertine imports into is called *Imported Music* unless you name it.
- **[How to check that Vespertine is bit-perfect on your own hardware](https://github.com/szeremeta1/Vespertine/blob/main/docs/VERIFICATION.md).** The guide covers:
  - exactly when the BIT-PERFECT badge appears;
  - what Vespertine reads back from macOS to decide;
  - the tests that compare output sample for sample;
  - three checks that don't rely on Vespertine at all.
- **Command-line tools are now `vespertine-probe`, `vespertine-library`, `vespertine-demo` and `vespertine-analyze`.**

### Install
Download **Vespertine-0.6.0.dmg**. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
