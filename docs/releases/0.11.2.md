**Vespertine now speaks 44 languages, welcomes new users with a setup assistant, remembers the output you chose, starts DSD CUE tracks at once, and can check its own signal path bit for bit with a loopback test.**

### 44 languages
- **Translated throughout.** The app, its menus, settings, error messages and VoiceOver labels are available in Amharic, Arabic, Bengali, Chinese (Simplified, Traditional for Taiwan, Traditional for Hong Kong), Czech, Danish, Dutch, Filipino, Finnish, French, German, Greek, Gujarati, Hausa, Hebrew, Hindi, Hungarian, Indonesian, Italian, Japanese, Kannada, Korean, Malay, Malayalam, Marathi, Norwegian Bokmål, Persian, Polish, Portuguese (Brazil and Portugal), Punjabi, Romanian, Spanish, Swahili, Swedish, Tamil, Telugu, Thai, Turkish, Ukrainian, Urdu and Vietnamese. Vespertine follows the language set for it in System Settings.
- **Written for each language.** Counts use each language's plural forms, numbers use local decimal separators, and sentences are translated whole instead of being assembled from fragments.
- **Right to left.** Arabic, Hebrew, Persian and Urdu lay out right to left. The transport controls and seek bar stay left to right, as in Apple's own apps.
- **Readable scripts.** Letter spacing and the monospaced face are turned off for Arabic, Indic and Thai scripts, where they pull letters apart.
- **Any library, any language.** Analysis summaries and the starter smart playlists are translated when shown, so a library made in one language reads correctly in another.
- **No Russian.** Vespertine has no Russian localization, and the release build removes the one Sparkle bundles.
- The translations are careful machine translations, checked on screen but not yet reviewed by native speakers. Corrections are very welcome: please [open an issue](https://github.com/szeremeta1/Vespertine/issues/new/choose).

### Setup assistant
- **A guided first launch.** A new library opens to a six-step assistant: welcome, where your music lives (leave files in place, or copy and organize them; then find music on this Mac, add a folder or connect to a server, with live counts), which output to use (every connected device, with the best one marked), sound (exclusive access, ReplayGain, and whether the volume keys follow Vespertine), extras (background quality checks, cover art, automatic updates), and a summary.
- **Only once.** It shows until you finish or skip it. Libraries that already have music never see it, and **Vespertine › Setup Assistant…** brings it back.
- **Calm with Reduce Motion.** Pages cross-fade and the background stays still when Reduce Motion is on.

### Remembered output
- **Your choice sticks.** The output you choose is remembered and used whenever it's connected, even when it wasn't there at launch.
- **A stand-in meanwhile.** Until it returns, Vespertine plays on a stand-in, set in **Settings › Playback › "When the chosen output isn't connected, play on"**: the best connected output (the default), the Mac's sound output, or nothing (wait for it). The best output is an external USB, Thunderbolt, PCI or FireWire device first, then the Mac's sound output, then built-in, then HDMI, Bluetooth and AirPlay; virtual devices only if nothing else is there.
- **Clear about it.** The output menu keeps your choice checked as NOT CONNECTED · USING the stand-in, and the inspector says "Waiting for …" instead of "Preparing output…". Playback moves back when the output is plugged in again.
- **Brief dropouts.** If the chosen output disappeared moments ago (AirPods reconnecting), Vespertine waits up to 10 seconds for it before using the stand-in. A dropout in the middle of a song still pauses and waits, as before.
- **A DAC on another port.** A DAC that comes back under a new identity (plugged into another USB port) is recognized and keeps its rate, DoP, receiver, Spatial Audio and EQ settings.

### Match 16-bit sources
- **New setting.** **Settings › Playback › Output › Match 16-bit sources**, off by default and available with exclusive access. When it's on, a 16-bit file goes to a DAC that has a 16-bit mode at that rate as 16-bit, instead of zero-padded to 24 or 32 bits. The samples are identical either way.
- **When it applies.** Only for 16-bit PCM at its own rate and channel count, on a device held exclusively (not the Mac's own speakers or headphone jack), with no digital volume, EQ, ReplayGain, Spatial Audio or downmix. DSD, DoP and bitstream playback are never affected.
- **The signal path says what happened.** A Match 16-bit sources step reads what the DAC accepted: sent as 16-bit, no 16-bit mode at that rate (sent as 24-bit, same samples), or the device kept its depth despite the request.
- **Other apps unaffected.** When matched playback ends, the device goes back to its full bit depth.

### Loopback test
- **Check Vespertine's own output path.** **Controls › Loopback Test…** (also in Settings › Playback) plays a test signal through the real decoder and engine to a virtual loopback device, records what comes back and compares it sample by sample. Choose a quick run (24-bit at 44.1 and 96 kHz, 16-bit padded, and a gapless pair) or a full run (every common rate from 44.1 to 384 kHz at 24-bit, 16-bit padded and matched, 32-bit integer, gapless and 16→24 pairs).
- **Diagnoses, not just pass or fail.** A failure names what went wrong: dropped or repeated frames, truncation, dither, a gain change, swapped or inverted channels, unlocked clocks, or a recording glitch in the test setup.
- **Results you can keep.** Copy Report puts a Markdown report on the clipboard. Results are saved per device, format, settings, macOS version and app version, and the inspector's signal path shows the playing format's last result as "Loopback (software check)".
- **Honest about its scope.** It checks Vespertine's software path only. It says nothing about a DAC and never feeds the BIT-PERFECT badge. It needs a virtual loopback device: the source tree's `scripts/install-loopback-device.sh` builds a dedicated "Vespertine Loopback" from BlackHole. Recording that device asks for microphone permission once; no microphone is ever recorded. See [LOOPBACK.md](https://github.com/szeremeta1/Vespertine/blob/main/docs/LOOPBACK.md).
- **From the command line.** `vespertine-probe loopback [--quick|--full] [--json] [--markdown <path>]` runs the same test unattended.

### Faster DSD
- **DSD CUE tracks start at once.** A track deep into a DSF or DSDIFF CUE album, and any seek in a long DSD file, used to read the file from the start up to that point: 20 seconds or more from a network share. Vespertine now jumps straight to the position, so DSD starts and seeks as quickly as FLAC. The DSD and converted PCM samples are identical to reading straight through.

### Fixed

### Known issues
- **Volume sync with exclusive access.** While Vespertine holds a DAC exclusively, macOS moves the Mac's sound output to another device, often the built-in speakers, and Vespertine copies the DAC's volume onto that output so the volume keys keep working. Other apps' sounds on that output then play at the DAC's level, which can be much louder than usual, and the DAC's own Mac-side level can drift below 100%. A fix is in progress. Until then, turning off exclusive access avoids it, or check the DAC's level in Audio MIDI Setup if bit-perfect playback matters.
- Some German and Portuguese labels are cut off, and a stray icon appears on the search page.
