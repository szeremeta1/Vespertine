**Fake hi-res analysis for surround music, and share addresses kept private.**

### Fixed
- **Multichannel files are analyzed properly.** Analysis of 5.1, 7.1 and other surround files read every channel as silence, so they were always reported as genuine with a 0-bit effective depth. Every channel is now measured: true bit depth, bandwidth, peak, clipping, and lossy-origin or upsampling evidence. Results saved by earlier versions for surround tracks are cleared, so they're analyzed again.
- A file that decodes to nothing but silence is never called genuine.
- **Albums on network shares no longer show the server's address.** Album pages and the tag editor show locations as *Share name › Artist/Album* instead of the mount folder, which included the server's address.

### Install
Download **Nocturne-0.5.3.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
