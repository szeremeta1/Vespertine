**Nocturne now updates itself.** From this version on, Nocturne checks for new releases in the background and can install them for you. Every update is signed by the developer and verified before it is installed.

### Install
Download **Nocturne-0.2.0.dmg**, open it, and drag Nocturne to Applications. This one manual install is needed coming from 0.1.x; after that, updates arrive automatically.

**Requires** macOS 26 or later, on Apple silicon or Intel. The app and the disk image are signed with a Developer ID, notarized by Apple, and stapled.

### What's new
- **Automatic updates** via [Sparkle](https://sparkle-project.org). Nocturne checks daily, and you can choose **Check for Updates…** in the Nocturne menu at any time. Settings → Updates lets you turn off checks or turn on fully automatic installs.
- **Signed update feed.** Each update is signed with an EdDSA key and checked against the app's code signature before installing.
- **Redesigned installer window**, in Nocturne's obsidian & brass style.
