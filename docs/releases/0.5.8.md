**Network shares reconnect by themselves, reliably.**

### Fixed
- **Shares that disconnected couldn't reconnect.** On current macOS, the place Nocturne mounted shares (inside its Application Support folder) is protected app data, and macOS refused to let Nocturne mount a share there again. The share stayed offline with a misleading "The server didn't accept that name and password". Shares now mount where macOS keeps network volumes (still hidden from the Finder sidebar), and your library follows them automatically.
- **Saved share passwords are always found.** Nocturne now reads the login keychain, where macOS and Finder keep network passwords, and saves new ones there too.

### Improved
- **Self-healing connections.** Besides reconnecting after sleep, network changes and server restarts, Nocturne notices a share that still looks connected but has stopped answering, and reconnects it by itself.
- **Clearer problems.** Wrong passwords, missing passwords and macOS permission problems each have their own message. If a password is missing, **Enter Password…** in the share's right-click menu fixes it in one step. Connection failures are written to the system log with their exact cause.

### Install
Download **Nocturne-0.5.8.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
