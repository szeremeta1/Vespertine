**Network shares reconnect by themselves, reliably.**

### Fixed
- **Shares that dropped couldn't reconnect.** On recent macOS, Nocturne looked for your saved share password in the wrong keychain, found nothing, and tried to connect without it, so the server refused and the share stayed offline ("The server didn't accept that name and password"). It now reads the login keychain, where macOS and Finder keep network passwords, and saves new ones there too.

### Improved
- **Self-healing connections.** Besides reconnecting after sleep, network changes and server restarts, Nocturne now notices a share that still looks connected but has stopped answering (for example after the server rebooted) and reconnects it by itself.
- **Clearer problems.** If a password really is missing, the share says so, and **Enter Password…** in its right-click menu fixes it in one step. Every connection failure is also written to the system log with its exact cause.

### Install
Download **Nocturne-0.5.8.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
