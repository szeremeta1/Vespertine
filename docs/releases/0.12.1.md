**Vespertine now plays smoothly from slow network shares, analyzes big libraries faster with shares included, plays hi-res on small USB-C DACs at the highest rate they offer, and keeps the keyboard and multi-selections where you expect them.**

### Network shares
- **Smooth playback from slow shares.** On a share that isn't very fast, playback could stutter and stall every few seconds, and pause, skip and seek could take seconds to respond. Vespertine now decodes a song from a share several seconds ahead, so a slow read no longer interrupts what's already buffered, and pause, skip, seek and output changes apply right away.
- **Fewer, shorter interruptions.** If the share falls behind more than once in a short time, Vespertine waits for a bit more audio before resuming, so you get a few longer pauses instead of a stop every few seconds.
- **The song comes first.** Copying a song to the local cache now steps aside while that song's buffer is running low.
- **No more crackling.** Songs from a share mounted in the Finder and added as a regular folder now pause to buffer instead of crackling.

### File analysis
- **Network shares are included.** Analyze Library now covers songs on network shares too. It still pauses while music plays from a share, so playback goes first.
- **Faster on big libraries.** Local files and share files are analyzed side by side instead of one queue waiting on the other, and local analysis uses half of the Mac's cores.
- **Progress in the sidebar.** A running library analysis shows its progress in the sidebar wherever you are, with a Stop button.
- **Several songs at once.** Choosing Analyze with several songs selected analyzes all of them and keeps the selection.

### USB DACs
- **Hi-res isn't cut down to 44.1 kHz.** On a DAC whose top rate is below the music's, such as a 96 kHz USB-C adapter, 176.4 kHz, 352.8 kHz and DSD used to play at 44.1 kHz. They now play at the DAC's top rate, keeping everything it can reproduce. Vespertine still uses an exact divisor of the music's rate when that keeps at least half of the DAC's top rate, such as 176.4 kHz for 352.8 kHz music on a 192 kHz DAC.
- **Real names for USB DACs.** A DAC that calls itself just “Headphone”, such as the UGREEN CM450, now shows its product name in the device picker and the signal path.
- **Loopback test with a muted loopback device.** If the Vespertine Loopback device was muted or turned down, every case ended with “No signal reached the input”. The test now turns it up for the run and puts it back afterwards.

### Fixed
- **Pause responds at once.** Pausing a song that streams from a slow network share stopped the sound right away, but the button could keep showing pause for a long while, and pressing it again paused instead of resuming. The button now switches as soon as you press it, and a second press resumes. The media keys behave the same way.
- **Keyboard follows your click.** Clicking a song gives that list the keyboard, so the arrow keys, Return and ⌘A act on the songs instead of the sidebar. The selected row's text, tags and heart stay readable on the highlighted row.
- **Multi-selections hold.** A multi-selection no longer shrinks on its own when another page was open before. A plain click inside a multi-selection selects just that song, and double-click or Return plays the song you chose.
- **⌘A on a big library.** Selecting the whole library froze the window for several seconds while the inspector read every song's tags. That work now runs in the background.

### Known issues
- A stray icon can appear next to the sidebar button while the search field is active.

### Install
Download **Vespertine-0.12.1.dmg**, or let Vespertine update itself. Requires macOS 14.4 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled. Homebrew: `brew upgrade --cask vespertine`.
