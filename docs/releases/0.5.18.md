**Fixes for DTS CD albums, and MP3 original dates and labels.**

### Fixed
- **The last track of some DTS CD albums wouldn't play** ("An internal decoder error occurred."). Its length from the CUE sheet ran a fraction of a millisecond past the end of the file, and the track was refused. CUE tracks are now clamped to the audio that's actually there. (Seen on *Brothers in Arms*.)
- **Album sizes are right for albums stored as one file with a CUE sheet.** The file was counted once per track, so a 575 MB disc showed as 5 GB.
- **MP3s' original release date and label are read** (ID3 `TDOR`/`TORY`, `TPUB` and `TXXX` fields), so MP3 albums are dated by their original release too.

### Install
Download **Nocturne-0.5.18.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
