**More reliable server-side analysis results.**

### Fixed
- **Results from a server's analysis are always picked up after the server tidies its index.** Nocturne now recognizes a rewritten index by its contents rather than by the file's creation date, which some file servers don't update, so no result is ever skipped.

### Install
Download **Nocturne-0.5.7.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
