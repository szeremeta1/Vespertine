**A fix for a crash when analyzing multichannel files.**

### Fixed
- **Analyzing a 5.1, 7.1 or other multichannel file quit Nocturne.** Analysis (and playback) now handle any channel count; a file Nocturne can't read is reported instead.
- A malformed server address in **Connect to Server…** is rejected instead of risking a crash.

Everything from 0.4.0 is included: network shares with caching, fake hi-res detection with saved results, Find Music on This Mac and Enrich Metadata.

### Install
Download **Nocturne-0.4.1.dmg**, or let Nocturne update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID, notarized and stapled.
