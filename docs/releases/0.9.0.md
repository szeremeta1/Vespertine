**Vespertine is now signed with its developer's own Apple Developer ID, stays responsive on slow network shares and large libraries, and fixes everything a full code review turned up.**

### Signed by Alexander Szeremeta
- **Vespertine is now signed with Alexander Szeremeta's own Developer ID** (team `7WMQ9ZV6V8`), not the Developer ID that signed earlier versions. It's still notarized by Apple, and updates are still checked against the same Sparkle key, so this update installs like any other.
- **macOS asks once for saved passwords.** Because the signer changed, the first time this version uses a share password or your ListenBrainz token that an earlier version saved, macOS asks for your login keychain password. Choose **Always Allow** and it won't ask again. macOS may also ask once more for access to network volumes or your local network. Vespertine no longer freezes while that prompt is up.
- **The update feed is signed too.** Every update was already signed. Now the whole list of updates is as well, so a tampered feed is refused.

### Changed
- **Opening a song from Finder that's already in your library plays it straight away**, without first checking the whole folder or share it lives in.
- **Large libraries stay smooth while analysis runs.** Saving each analysis result no longer reloads every page, and the queue no longer walks thousands of share files after each one.
- **Large server analysis indexes import quickly over slow links.** A 190 MB index went from 5.4 s and 259 MB of memory to 1.5 s and 20 MB, and an import that runs out of time keeps its progress. `vespertine-analyze` uses about an eighth of the memory on big libraries.
- **Launch is faster after an analyzer update.** Re-checking stored analysis results now runs once per update, in the background, instead of on every launch.

### Fixed
- **Editing tags on a network share can no longer corrupt the file.** On shares and other disks that can't make instant copies, the edit goes to a full copy that replaces the original only once it's complete, so a dropped connection or a sleeping Mac leaves the original intact. The undo entry is saved before the write.
- **A sleeping NAS no longer freezes the tag editor.** Whether a file can be edited is checked once, in the background, with a time limit.
- **Shuffling or reordering the queue during playback can no longer play stale audio.** Under heavy load, the audio thread could read past the point the queue was rewound to and play about 30 seconds of old audio.
- **Switching outputs back and forth quickly no longer leaves playback silent.**
- **7.1 Dolby Digital Plus is sent to receivers correctly.** Dependent substreams are now grouped into whole bursts, and from MP4 and M4A files the full 7.1 stream is sent, not just its 5.1 core. Seeking and durations are right for these files too.
- **After DSD, a DAC goes back to its own sample rate** when you switch to another device, or when a Dolby Atmos song follows on the same DAC.
- **One damaged frame in a DTS-HD or TrueHD file no longer ends the song early.**
- **Library-only edits follow a file you move or rename.** Edits to CUE tracks and to files on read-only shares were lost when the file moved.
- **Vespertine leaves Time Machine's network mounts alone.** It could treat Time Machine's hidden mount of the same share as its own and force it off a slow connection.
- **An interrupted import no longer leaves a partial file behind** to be scanned into the library.
- **Stop in analysis stays stopped.** Analyses paused for share playback no longer start again by themselves.
- **Saving a share password or ListenBrainz token reports a failure** instead of silently not saving.
- The Connect to Server sheet and Find Music no longer check the keychain or the disk's free space on every keystroke.
- `vespertine-library` reports a missing option value instead of crashing, and `vespertine-analyze` stops a hung ffmpeg instead of waiting for ever.

### Accessibility
- Every field in the tag editor has a VoiceOver name, including Lyrics and the totals in "Track … of …" and "Disc … of …".
- The file checkboxes in Find Music are named after the file, and filter chips say whether they're on.

### Install
Download **Vespertine-0.9.0.dmg**, or let Vespertine update itself. Requires macOS 26 or later on Apple silicon or Intel. Signed with a Developer ID (Alexander Szeremeta, `7WMQ9ZV6V8`), notarized and stapled. Homebrew: `brew upgrade --cask vespertine`.
