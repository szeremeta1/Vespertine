**Vespertine now runs on macOS 14.4 Sonoma and later, gains a parametric equalizer with AutoEQ import, and brings your playlists over from M3U files and Apple Music. This is the 1.0 beta: please try it on your own DAC and [tell us how it went](https://github.com/szeremeta1/Vespertine/issues/new?template=dac_report.yml).**

### Runs on Sonoma and Sequoia
- **Vespertine now needs macOS 14.4 or later**, not macOS 26. Any Mac that runs Sonoma can update to 14.4. It was tested end to end on macOS 14 and 15: playback, the signal path, the equalizer and playlist import.

### Parametric equalizer
- **Window › Equalizer (⌥⌘E).** Up to 20 peak, shelf, low-pass and high-pass bands and a preamp, run in 64-bit and dithered to your DAC's word length. Edits are heard within one device buffer.
- **Import a headphone correction** from [AutoEQ](https://autoeq.app) (its `ParametricEQ.txt`) or an Equalizer APO configuration, and export your own.
- **See the curve and whether it can clip.** When a curve can push the signal over full scale, the Equalizer says so and sets the preamp that prevents it in one click.
- **A preset per output**, so your headphone amp gets its correction and your speakers don't.
- **Honest about what it does.** The EQ is off by default. While it's on, the signal path shows an Equalizer step and says EQUALIZER instead of BIT-PERFECT; a preset that changes nothing counts as off. It never touches DoP, bitstream to a receiver, or Atmos that macOS renders.

### Playlists from other players
- **Import Playlist…** reads M3U and M3U8 files, from Playlists › + or the File menu.
- **Import Apple Music Library…** reads the library Music exports (File › Library › Export Library…): its playlists, loved songs as favorites, and play counts, raised to Music's and never counted twice.
- Entries match songs already in your library by file path, or, when a file has moved, by title, artist and length when exactly one song fits.
- **Export Playlist…** in a playlist's context menu writes an extended M3U8 that other players read.

### Fixed
- **Page headers fit narrow windows.** Titles and buttons no longer break mid-word ("Albu / ms"); in a narrow window the buttons move below the title.
- "1 albums · 1 tracks" now reads "1 album · 1 track".
